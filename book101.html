はじめに

パソコンやスマートフォンは、見た目にはただの機械です。けれど実際には、 キーボードで文字を打てば文字が現れ、検索をすれば情報が出てきて、ゲームを開けば画面が動きます。 それは、機械が勝手に考えているからではありません。人間があらかじめ「こういうときはこう動く」と命令を書いているからです。

その命令を書くための言葉のひとつがPythonです。Pythonは世界中で広く使われているプログラミング言語で、 Webページづくり、データの整理、AI、ゲーム、ロボット、自動化など、さまざまな場面で活躍しています。 このブログでは、「自分の名前を入れるとあいさつページができる」という小さな作品から出発し、 「CPUは何をしているのか」「0と1だけでどうして動くのか」「100件の名言をどうやって自動で集めるのか」 「検索機能やbookシリーズの自動生成にPythonはどう関わるのか」まで、ひとつずつ階段を上がるように整理していきます。

図1　Pythonは、人間の考えをコンピュータが実行できる形へ近づける「命令書」の役割をします。

第1章：Pythonって何もの？

🐍 パイソンってどう読む？（名前の由来）

「Python」は「パイソン」と読みます。英語では大きなヘビを意味しますが、 本当の名前の由来はイギリスのコメディ番組 Monty Python's Flying Circus から来ています。 難しそうに見えても、親しみやすい背景があるのです。

✅ よくある間違い：ピソン ❌ / ピュートン ❌ / パイトン ❌ → パイソン が正解！

📜 Pythonは「コンピュータへの命令書」

Pythonはプログラミング言語です。プログラミング言語とは、コンピュータに何をしてほしいかを伝えるための言葉。 たとえば print("こんにちは") と書けば、画面に「こんにちは」と表示されます。 つまり、Pythonは「考えたことを作業の流れに変える」命令書です。

⚡ 何ができるのか？

🌐 Webページを作る
HTMLを自動で書き出し、大量のページを用意できます。
🤖 面倒な作業を自動化する
同じ手順を何十回も疲れずにくり返せます。
🎮 AIやゲームも動かせる
応用範囲が広く、学びを深めるほど世界が広がります。

第2章：はじめてのプログラム — あいさつのページを作る

📌 プログラムの3ステップ　入力 → 処理 → 出力

  • 入力：名前を入れる
  • 処理：「こんにちは ○○さん！」という文章を作る
  • 出力：その文章をHTMLファイルに書き出す
図3　プログラムの基本形は「入力 → 処理 → 出力」。最初にこの流れをつかむと応用が広がります。

💻 実際にコードを書いてみる（hello.py）

print("=== あいさつプログラム ===")
name = input("あなたの名前を入力してください: ")

html = "<h1>こんにちは " + name + " さん！</h1>"

with open("hello.html", "w", encoding="utf-8") as f:
    f.write(html)

print("完了しました！")

▶ 実行する（PowerShellの使い方）

cd Desktop
python hello.py

名前（例: yuta）を入力すると、デスクトップに hello.html が作られます。ブラウザで開くと「こんにちは yuta さん！」と表示されます。

✨ ここが第一の感動ポイント：Pythonは画面の中だけでなく、作品としてファイルを残せるのです。

第3章：Pythonはどう動いているのか？ — コンピュータのしくみ（深掘り）

⚙️ CPUって何をしているの？

CPU（中央処理装置）はコンピュータの「頭脳」です。1秒間に数十億回という速さで、

  1. 命令を読み込む（メモリから「これやってね」を取得）
  2. 解読する（どんな命令かを理解）
  3. 実行する（計算したり、データを移動したり）
  4. 結果を保存する

このサイクルをひたすら繰り返しています。Pythonで書いたプログラムも、最終的にはこのCPUのサイクルに変換されて動いています。

図4　CPUは「読む→解読→実行→保存」を高速で繰り返す

🔢 0と1だけでなぜ動く？ ─ トランジスタと2進数

コンピュータ内部では、すべての情報が 0 と 1 だけで表現されています。なぜでしょうか？

💡 答えは「トランジスタ」という部品にあります

トランジスタは「電気が流れる(ON) / 流れない(OFF)」の2つの状態しか持てません。
このONを「1」、OFFを「0」と決めると、たった2つの状態だけで様々な情報を表現できます。

• 数字： 1 → 1, 2 → 10, 3 → 11, 4 → 100 ...
• 文字： 「A」は 01000001 という8桁の0と1のパターン
• 画像： 1ピクセルの色も0と1の組み合わせ

シンプルだからこそ、トランジスタは小さく作れて、高速で切り替えられます。現在のCPUには数百億個ものトランジスタが詰まっています。
図5　トランジスタのON/OFFが、すべての情報処理の土台になっている

🗣️ Pythonは「通訳者」 ─ なぜ機械語に変換する必要があるのか？

CPUが理解できるのは「0と1の命令（機械語）」だけです。でも人間が0と1だけでプログラムを書くのは大変です。

🐍 Pythonの役割：
「print("こんにちは")」という人間の言葉に近いコードを、
「10110000 00000001 ...」というCPUが理解できる0と1の命令に変換します。
この変換をしてくれるから、私たちは「考えたいこと」に集中できるのです。
【あなた】「画面に『こんにちは』と表示して」
↓ Pythonコード： print("こんにちは")
↓ Python（通訳者）が機械語に変換
↓ CPU（0と1の世界）で実行
↓ 画面に「こんにちは」が表示される
📌 まとめ： コンピュータは「0と1のON/OFF」で動き、Pythonはその複雑さを隠して「人間が考えたいこと」に集中できるようにする「通訳者」です。

第5章：Pythonによる自動化！ —— 名言を100件集めるプログラム

🧑‍💻 手作業とプログラムの違い

人間：サイトを開く → コピー → Excelに貼る → 次のページ… 時間と手間。
Python：一度プログラムを書けば、あとは全部自動で処理。

📦 必要な道具

道具役割
requestsWebサイトにアクセス
BeautifulSoupHTMLから必要な情報を取り出す
csv表として保存
timeサーバーにやさしく待機
import requests
from bs4 import BeautifulSoup
import csv
import time

def scrape_quotes(url):
    response = requests.get(url)
    soup = BeautifulSoup(response.text, "html.parser")
    results = []
    quotes = soup.find_all("div", class_="quote")
    for q in quotes:
        text = q.find("span", class_="text").text
        author = q.find("small", class_="author").text
        results.append({"text": text, "author": author})
    return results

all_quotes = []
for page in range(1, 6):
    url = f"https://quotes.toscrape.com/page/{page}/"
    data = scrape_quotes(url)
    all_quotes.extend(data)
    time.sleep(1)

with open("quotes.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.DictWriter(f, fieldnames=["text", "author"])
    writer.writeheader()
    writer.writerows(all_quotes)

print("完了！quotes.csv を確認")

実行すると quotes.csv ができ、名言の一覧表が完成します。

🤖 PythonとAI ─ なぜAIでPythonが使われるのか？

現代のAI（ChatGPT、画像生成AIなど）の多くはPythonで作られています。なぜでしょうか？

  • 豊富なライブラリ：TensorFlow、PyTorchなど、AI開発用の道具が無料で使える
  • 読みやすさ：複雑なAIのアルゴリズムもPythonなら理解しやすい
  • コミュニティの大きさ：困ったときに情報が見つかりやすい
  • データ分析との相性：大量のデータを扱うのに適している
✨ 作る → 見る → 探す → 学ぶ（AI） まで、Pythonはあなたのアイデアを形にする「万能な道具」です。

まとめ

  • Pythonは「入力 → 処理 → 出力」の基本で動く
  • CPUは0と1（トランジスタのON/OFF）で動き、Pythonはそれを人間にわかりやすくする「通訳者」
  • 自動化を使えば、人間が手間をかける作業を機械に任せられ、創造的な時間が増える
  • Pythonは他の言語（C, Java）と比べて「読みやすさ」が最大の特徴
  • 検索機能やbookシリーズの生成、さらにはAI開発まで、Pythonの世界は広がっている

🚀 次に学ぶと良いこと

  • AIを使った自動生成（OpenAI APIなど）
  • メール送信の自動化（smtplib）
  • 自分の好きなサイトから情報を集めるスクレイピング(Webページの中から必要な情報だけを自動で取り出すこと)
  • Webアプリケーション（FlaskやDjango）の作成
